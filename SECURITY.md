# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please report security vulnerabilities by opening a [GitHub Security Advisory](https://github.com/metyatech/skill-human-ai-system-builder/security/advisories/new).

Do not open a public issue for security vulnerabilities.

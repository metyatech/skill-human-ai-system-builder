# Contributing

Thank you for your interest in contributing to `skill-human-ai-system-builder`.

## Development setup

```bash
git clone https://github.com/metyatech/skill-human-ai-system-builder.git
cd skill-human-ai-system-builder
```

Install the required tools:

```bash
npm install -g markdownlint-cli compose-agentsmd
```

## Verification

```bash
pwsh -File scripts/verify.ps1
```

## Scope

Keep changes focused on reusable design guidance for systems jointly managed by humans and AI.

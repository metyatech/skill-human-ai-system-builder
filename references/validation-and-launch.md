# Validation and launch

Validation should appear where the human is already working whenever practical.

Validation layers:

- live diagnostics in the primary human work surface
- save-time validation before apply
- build-time validation before artifact generation
- commit-time validation in the repository

Human launch defaults:

- prefer launcher or double-click flows for routine work
- keep CLI behind the scenes when the human does not benefit from it
- if new-item creation cannot start from a document directly, provide a launcher or shortcut

AI launch defaults:

- agent request triggers direct work on the canonical store
- avoid requiring AI to operate through the human GUI unless the task is inherently visual

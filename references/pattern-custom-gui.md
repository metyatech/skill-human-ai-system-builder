# Pattern: custom-gui

Use this pattern when a dedicated application is the clearest human work surface.

Typical shape:

- canonical store: database or structured files
- human surface: custom web or desktop GUI
- ai surface: API, files, or service adapter
- sync: managed by the application itself
- validation: shown directly in the custom GUI
- outputs: generated through application actions

Good fit:

- management consoles
- approval workflows
- inventory and record systems
- systems where search and state dominate editing
